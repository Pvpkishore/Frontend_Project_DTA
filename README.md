# Entrée Food Storefront

A responsive front-end prototype for **Entrée**, a food ordering storefront. The project brings together independently built sections into a single shopping experience.

## Preview

Open [`Entree_Combained_website/Combinedpages.html`](Entree_Combained_website/Combinedpages.html) in a browser to view the complete site.

No build step or package installation is required.

## Features

- Header with product search, account details, notifications, profile, and cart controls
- Promotional carousel
- Account activity and recent-order summary
- Product category, recommended, new-stock, and limited-availability sections
- Exclusive brands and frequently bought items
- Cart view and site footer
- Responsive layouts for desktop, tablet, and mobile screens

## Project structure

```text
Frontend_Project_DTA/
├── Entree_Combained_website/  # Final assembled storefront and its assets
│   ├── Combinedpages.html     # Main entry page
│   ├── css/                   # Combined page styles
│   ├── images/                # Product images
│   ├── images1/               # Exclusive-brand images
│   ├── HeaderSvgs/             # Header assets
│   └── Footer_svgs/            # Footer assets
├── Eshitha_Pages/             # Cart, brands, and frequently-bought sections
├── Kishore_pages/             # Header, footer, carousel, and account activity
└── Mansi_pages/               # Category and product-list sections
```

## Technologies

- HTML5
- CSS3 and SCSS source files
- Font Awesome icons (loaded from CDN)

## Running locally

1. Clone or download this repository.
2. Open `Entree_Combained_website/Combinedpages.html` in a modern browser.

For live reload during development, serve the project folder with an editor extension such as VS Code Live Server.

## Notes

The individual folders retain the original section pages and styles. The `Entree_Combained_website` folder is the integration target and should be used for reviewing the complete experience.
